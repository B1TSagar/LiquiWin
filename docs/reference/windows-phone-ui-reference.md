# Windows Phone UI reference

The exact values behind LiquiWin's Windows Phone presets and motion, researched on 2026-10-27 for the [sub-project 1 spec](../superpowers/specs/2026-10-27-liquiwin-launcher-start-screen-design.md). The spec holds the design decisions. This file holds facts and numbers, each with its source.

**Reading this file:**
- Pixel values are for Windows Phone's 480-pixel-wide view unless stated. On Android, scale them by screen width: dp = px × (screen width in dp ÷ 480).
- (S) marks a value that comes only from a secondary source or a search snippet.
- "Unverified" marks a best guess. When the implementation settles one, record the chosen value here.
- The notes for LiquiWin at the end say where the spec departs from these originals on purpose.

## 1. Start screen
- **WP7.0/7.5**: one tile size, 173x173, gap 12, count badge 37x37 ([diagram](https://learn.microsoft.com/en-us/previous-versions/windows/apps/images/jj553779.tiles_concept_mangotemplatesizes(en-us,vs.105).png), [doc](https://learn.microsoft.com/en-us/previous-versions/windows/apps/jj553779(v=vs.105))). 2 columns. A black right strip held only the arrow ([Genbeta](https://www.genbeta.com/movil/windows-phone-7-8-primeras-impresiones)). Arrow sat at the top ([MS WP8 Start story](https://blogs.windows.com/windowsexperience/2012/11/02/the-story-behind-the-windows-phone-8-start-screen/)); flick left also opens the app list ([MS Mango blog](https://blogs.windows.com/windowsexperience/2011/07/08/navigation-improvements-coming-in-mango/)). Strip width unverified (12+173+12+173 = 370 of 480, derived).
- **WP7.8** (Feb 2013): WP8-style Start, resizable tiles, 20 accents ([Wikipedia](https://en.wikipedia.org/wiki/Windows_Phone_version_history)); strip removed, arrow moved to the end, 4 small per medium, swipe-left still works ([Genbeta](https://www.genbeta.com/movil/windows-phone-7-8-primeras-impresiones)).
- **WP8.0**: small/medium/wide, up to 4 small across (Microsoft found 3 too limiting and 5 too small); gutter removed, arrow to bottom ([MS blog](https://blogs.windows.com/windowsexperience/2012/11/02/the-story-behind-the-windows-phone-8-start-screen/)). WXGA (768 wide): small 159, medium 336, wide 691 (=2x336+19), gap 19, badge 59x59 ([Tiles WP8](https://learn.microsoft.com/en-us/previous-versions/windows/apps/hh202948(v=vs.105)), [diagram](https://learn.microsoft.com/en-us/previous-versions/windows/apps/images/jj662925.ux_concept_tile_fliptemplatesizing(en-us,vs.105).png)). 480-base equivalents 99/210/432 ([Toolkit HubTile.cs](https://github.com/codeRuth/WPToolkit/blob/master/Microsoft.Phone.Controls.Toolkit/HubTile/HubTile.cs)); gap ~12 (derived). 6 small across (3 medium columns) only on large/1080p phones from GDR3, Oct 2013 ([Wikipedia](https://en.wikipedia.org/wiki/Windows_Phone_version_history)).
- **WP8.1**: "Show more tiles" = 3rd medium column on all devices, previously 1080p and some 720p phones ([Wikipedia](https://en.wikipedia.org/wiki/Windows_Phone_8.1)). Asset sizes at 1.0 scale: small 71, medium 150, wide 310x150 ([TileSize](https://learn.microsoft.com/en-us/uwp/api/windows.ui.startscreen.tilesize?view=winrt-26100), [catalog](https://learn.microsoft.com/en-us/previous-versions/windows/apps/hh761491(v=win.10))); gap undocumented (310=2x150+10, derived). **Large 310x310 is not supported on Windows Phone 8.1** ([MS](https://learn.microsoft.com/en-us/uwp/api/windows.ui.startscreen.secondarytilevisualelements.square310x310logo?view=winrt-18362)).
- **WP8.1 background**: photo shows through transparent tiles ([AllAboutWP](https://allaboutwindowsphone.com/flow/item/19417_Windows_Phone_81_set_to_get_cu.php)), parallax on scroll (S, [readme.lk](https://readme.lk/wp-8-1/)); Xbox Music/Office/Photos kept solid colours ([Expert Reviews](https://www.expertreviews.co.uk/technology/software-services/windows-phone-81-review)).
- **W10M**: tiles small/medium/wide only; "Show more tiles" scales between two presets ([Thurrott](https://www.thurrott.com/mobile/windows-phone/4722/windows-10-mobile-tip-customize-start)) and adds a column for medium tiles ([MS Lumia blog](https://blogs.windows.com/devices/2016/01/04/how-to-get-started-with-your-windows-10-lumia/)); Lumia 950 defaults to 3 columns, 4th needs lower display scaling (S, [WC](https://www.windowscentral.com/enable-four-columns-start-screen-lumia-950)). **Large tile on phones: most likely not in the final build**: early previews had it, dropped by build 10536, where tiles could no longer be resized to large (S, [Nokiapoweruser](https://nokiapoweruser.com/windows-10-mobile-to-ship-with-large-tiles-support/)); release guide lists three sizes (Thurrott above). No MS statement for W10M found (medium confidence).
- **W10M background**: None / Tile picture / Full-screen picture; transparency slider 0-100% only with full-screen ([Thurrott](https://www.thurrott.com/mobile/windows-phone/4722/windows-10-mobile-tip-customize-start)).

## 2. Live tiles
- WP7.1: one template (flip), medium only ([MS](https://learn.microsoft.com/en-us/previous-versions/windows/apps/jj553779(v=vs.105))). Flips happen at a random interval, so key information belongs on the front. Back text: medium 3 lines x ~13 chars, wide 3 x ~27; titles 19/39 chars ([Flip guidelines](https://learn.microsoft.com/en-us/previous-versions/windows/apps/jj662925(v=vs.105))).
- WP8 templates: Flip, Cycle (1-9 images, [doc](https://learn.microsoft.com/en-us/previous-versions/windows/apps/jj207036(v=vs.105))), Iconic. Iconic wide = 3 text lines (~33 chars each), icon max 110x110 small / 202x202 medium (best fit 70x110 / 130x202); wide shows the small icon when text present ([guidelines](https://learn.microsoft.com/en-us/previous-versions/windows/apps/jj662924(v=vs.105))). Default-tile template can't change ([doc](https://learn.microsoft.com/en-us/previous-versions/windows/apps/hh202948(v=vs.105))).
- Count: 1-99 ([StandardTileData.Count](https://learn.microsoft.com/en-us/previous-versions/hh203093(v=vs.110))); 0 hides it (MS sample comment, S). WNS badge: 1-99, >99 shows "99+", lower-right on all sizes ([badges](https://learn.microsoft.com/en-us/windows/apps/develop/notifications/badges)).
- WP8.1 catalog: Peek tiles flip front/back on phones (no scroll); image-collection = 6x3 grid of flipping blocks, an image uses 1 or 4 blocks, random order ([catalog](https://learn.microsoft.com/en-us/previous-versions/windows/apps/hh761491(v=win.10))). UWP peek image slides in from the top; background overlay defaults to 20% when text present ([adaptive tiles](https://learn.microsoft.com/en-us/windows/uwp/launch-resume/create-adaptive-tiles)).
- Timing: MS publishes no flip/cycle interval. Toolkit HubTile (emulates Start tiles): every transition 0.85 s, CubicEase-out; flip = RotationX 0->180 with face swap at 0.185 s; slide = TranslateY to -0.4566 x tile size ([generic.xaml](https://github.com/codeRuth/WPToolkit/blob/master/Microsoft.Phone.Controls.Toolkit.WP8/Themes/Generic.xaml)). Scheduler: first tick 2.5 s, then random 0.1-3.0 s (100 ms steps), 1 tile animating at a time, tile rests 3 ticks, random slide vs flip ([HubTileService.cs](https://github.com/codeRuth/WPToolkit/blob/master/Microsoft.Phone.Controls.Toolkit/HubTile/HubTileService.cs)). Forum: animation stops ~30 s after idle (S, [WC forum](https://forums.windowscentral.com/threads/live-tile-stop-moving.258280/)).
- People tile shuffles contact photos (S, [MS blog](https://blogs.windows.com/devices/2011/11/14/smart-tricks-with-live-tiles-on-the-nokia-lumia-800/)); grid size/timing unverified.
- Folders arrived WP8.1 Update 1 (GDR1, 4 Aug 2014) ([Wikipedia](https://en.wikipedia.org/wiki/Windows_Phone_version_history)): drag tile onto tile; resizable; inner apps can still show as live tiles; opens expanded on Start ([Wikipedia](https://en.wikipedia.org/wiki/Windows_Phone_8.1), [MS](https://blogs.windows.com/devices/2015/01/16/lumia-denim-using-live-folders-lumia/)). Folder-face preview and combined counts: unverified ([OnMSFT](https://onmsft.com/how-to/how-to-make-folders-on-your-windows-10-start-menu/) says W10M medium/large folders cycle inner live tiles, S).

## 5. Motion
Source: Windows Phone Toolkit (Ms-PL), [storyboards](https://github.com/codeRuth/WPToolkit/tree/master/Microsoft.Phone.Controls.Toolkit/Transitions/Storyboards). All ExponentialEase exp 6 unless noted.
- **Turnstile** (RotationY, opacity fades at the end of out, 10 ms fade-in): fwd-in -80 to 0, 350 ms EaseOut; fwd-out 0 to 50, 250 ms EaseIn; back-in 50 to 0, 350 ms; back-out 0 to -80, 250 ms.
- **Feather** ([TurnstileFeatherEffect.cs](https://github.com/codeRuth/WPToolkit/blob/master/Microsoft.Phone.Controls.Toolkit/Effects/TurnstileFeatherEffect.cs)): per-item delay x FeatheringIndex; centre of rotation X -0.2; fwd-in 350 ms, -80, 40 ms/item; fwd-out 250 ms, 50, 50 ms/item; back-in 350 ms, 50, 50 ms; back-out 250 ms, -80, 40 ms.
- **Slide** (offset 200 px + fade): left-in 500 ms, left-out 300 ms, up-in 350 ms, down-out 250 ms.
- **Swivel** (RotationX): fwd-in -45 to 0, 350 ms; fwd-out 0 to 90, 250 ms, exp 15; back-in -45 to -30 (0.2 s, hidden) then 0 at 350 ms; back-out 0 to 60, 250 ms.
- **Rotate** (RotateIn90Clockwise) RotationZ 90 to 0, 250 ms (exp 1) + sine fade; **Roll** RotationZ 0 to 45 (300 ms) to 90 (600 ms).
- **Tilt** ([TiltEffect.cs](https://github.com/codeRuth/WPToolkit/blob/master/Microsoft.Phone.Controls.Toolkit/Effects/TiltEffect.cs)): max angle 0.3 rad (17.2 deg), max depression 25 px, release after 200 ms delay over 100 ms, no easing by default; tilts toward the screen centre ([MS](https://learn.microsoft.com/en-us/archive/blogs/ptorr/updated-tilt-effect)).
- **List slide-in** ([SlideInEffect.cs](https://github.com/codeRuth/WPToolkit/blob/master/Microsoft.Phone.Controls.Toolkit/Effects/SlideInEffect.cs)): offset 50 px x line index; hold 350 ms, linear to 420 ms (90% of distance), exp-5 ease-out to 1050 ms.
- **Continuum** (not in Toolkit; WinJS, [source](https://github.com/winjs/winjs/blob/master/src/js/WinJS/Animations.js)): fwd-in 350 ms page scale 0.5 to 1, item translateY 225 to 0, content rotateX 80 to 0 and scale 1.5 to 1; fwd-out page 120 ms (1 to 1.1), item 152 ms (rotateX 80, scale 1.5, translateY 150); back-in page 200 ms (1.25 to 1), item 250 ms (rotateX 80 to 0, translateY -100 to 0); back-out 167 ms (1 to 0.5). WinJS turnstile: perspective 600, rotateY 80 to 0 in 300 ms, out 0 to -50 in 128 ms, stagger 50 ms (cap 1000).

## Notes for LiquiWin

How the spec uses these findings, including where it departs from the originals on purpose:

- **Large tiles** are LiquiWin's own addition, offered in every style. WP8.1 didn't support them, and Windows 10 Mobile most likely dropped them before release.
- **Tile animation** follows the Toolkit scheduler in section 2: one timer for the start screen, one tile started per tick, and each tile resting for 3 ticks (spec §5.4).
- **The W10M preset uses 4 columns**, a deliberate choice for today's larger screens. Windows 10 Mobile defaulted to 3 and needed lower display scaling for a 4th. Setting the grid-columns facet to 3 gives the original default.
- **Accents.** The WP8 set is the 20 in section 6, with Sienna (A0522D) rather than the Taupe found in some community lists.
- **Selawik** covers Latin scripts only, so text in other scripts uses the phone's own font. The font files ship unmodified, with the copyright, notice and licence text in About.
- **Folder faces.** The spec's 3×3 preview grid is LiquiWin's own design, because what the original folder face showed couldn't be verified.
- **Names.** WP7, WP8.1, W10M and Modern Metro are working preset names. They get neutral names before a store release (spec §2).
- **Samsung.** The longer hold for recent apps under a third-party launcher is a One UI limit that LiquiWin can't change (spec §1.5).
